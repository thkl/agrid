A signal-based Angular grid with virtual scrolling, editing, filtering, sorting, grouping, pinned columns, selection, pagination, and clipboard workflows.

AgridProvider

The provider is the grid's configuration boundary. It lets the same component API serve simple grids, repeated grids, and grids whose data or behavior changes at runtime.

OptionDefaultDescription
columns[]Typed column definitions.
datasourceEmptySignal-based row container.
controlNew controlFilters, sorting, grouping, pagination, and history.
locale'auto'BCP-47 locale for labels and date formatting.
rowHeight32Virtual-scroll row height in pixels.
allowAddRowsfalseShows an add-row placeholder.
autoAddRowsfalseAdds a row when navigation leaves the last row.
showControlColumnfalseShows row actions and reorder handles.
showSidebarfalseShows the column visibility sidebar.
serverSideFilteringfalseEmits filter and sort requests instead of applying them locally.
sortOption'multi'Use 'single', 'multi', or 'none'.
rowSelection'none'Use 'single', 'multi', or 'none'.
zebraStripesfalseAlternates data-row backgrounds.
showChangedCellIndicatorfalseMarks changed cells until persistence clears them.
confirmRowDeletefalseFades the target row and shows a localized in-row Yes/No confirmation.
readonlyfalseDisables all cell editing.
loadingfalseShows the loading overlay.

Set confirmRowDelete: true to protect context-menu and deleteRow() actions. Direct datasource removals remain immediate.

Dynamic options

provider.loading, provider.readonlyGrid, and provider.autoAddRows are writable signals. Update them without recreating the provider.

Use ColDef<T> to make field names and callbacks type-safe. Generic parameters are optional for existing untyped configurations.

PropertyRequiredDescription

editableNoSet to false for readonly cells.
lockedNoPrevents hiding, reordering, and unpinning.

formatterNoFormats the displayed value.
filterableNoEnables the column filter UI.
groupableNoEnables grouping from the column menu.

pinnedNoPins to 'left' or 'right'.

cellClassNoReturns a CSS class for the cell.
ISO date strings and Date objects are automatically formatted and sorted chronologically. A custom formatter takes precedence.

Saving a complete row

Use rowChanged when several field edits should become one API request. Moving between cells in the same row does not emit it. The event fires when navigation enters another row, filter focus clears the active cell, focus leaves the grid, or the sidebar Save button is used. 

{{ saveRowCode }}

Enable showChangedCellIndicator on the provider to display a corner marker after each committed change. Call clearChangedCells(event.originalIndex) only after the request succeeds. You can also clear selected fields or every marker.

Adding defaults in repeated grids

Use the provider and datasource carried by the event. This avoids coupling the event to the surrounding loop index. 

{{ addRecordCode }}
